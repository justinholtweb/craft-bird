# Plugin Store promo images

Marketing images for the Bird listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-bird](https://justinholt.com/plugins/craft-bird).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `bird-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

## Slides

| 1 | Cover — name, tagline, app icon, price | — |
| 2 | `0%` → *btw verlegd · export · zero-rated* | the whole pitch, in one line |

Every slide is pure CSS and type — there are no control-panel screenshots yet. When the CP settles,
screenshot slides can be added alongside these without redoing anything: copy the `.shot` /
`.viewport` pattern from `craft-appleseed-website/promos/slides.html`.

## The disclaimer is not optional

Bird integrates with Moneybird and is not affiliated with them. **Every slide carries the
disclaimer** — the cover in full, the rest in the footer lockup's right-hand slot. A new slide
copies an existing `.footer` block, disclaimer included.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#E2711D`, Jersey 20 for display, Inter for body.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the bird alone, no tile, filled white. Copied from `../src/icon-mask.svg`.

Watermark opacity is **0.022**, not the 0.05 used on plugins whose mark is a line drawing. Bird's
mark is a solid silhouette, and at 0.05 it reads as a grey shape across the left third of every
slide rather than as a watermark.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.
